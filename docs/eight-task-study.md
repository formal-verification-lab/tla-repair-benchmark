# Расширение исследования до восьми задач

Набор фиксируется до генерации: исходные HourClock, AsynchInterface, Barrier,
CigaretteSmokers и дополнительные Channel (893), TCommit (1127),
SimpleAllocator (1000), SpanTree (878). Итого четыре basic/easy и четыре
intermediate/medium из той же закреплённой ревизии TLA+-Bench.

Кандидат TokenRing (1054) исключён на подготовке: исходный cfg приводит к
ошибке свойства ALIAS с JAR 1.7.4. Исправлять cfg для включения не стали.
Все восемь выбранных пар Gold/cfg проходят проверку. Новые пары дают
12, 34, 400 и 236 состояний соответственно. Полные тексты остаются локально.

Одна новая исследовательская серия выполняется двумя заранее определёнными
блоками по четыре задачи. Это позволяет использовать существующий проверенный
формат учебного runner без изменения его ограничения состава задач.
Блоки различаются только выбором задач; модель, код, правила и параметры общие.
Каждая задача имеет три начальные генерации; у каждой один общий старт A/B/C.
Всего 72 ветви. Пилот каждого блока отдельный и не входит в основные данные.

Используется профиль format-guide-v2 и GigaChat-3-Ultra:32.9.16.9,
temperature 0.1, max_tokens 2048. Предел десять основных генераций включает
начальную; объяснения учитываются отдельно. Это протокол исследовательского
расширения, не замена строгой учебной оценки. Дополнительный checklist общий
для всех методов, не изменяется по результатам. Gold изолирован от запросов.

```sh
.venv/bin/python -m benchmark.task_dataset --selection configs/tasks-extension.json \
  --output data/tasks-extension --jar data/lora-pilot/tla2tools.jar
caffeinate -i scripts/run-eight-task-study.sh
```

Сохраняются все успехи, исчерпания лимита и технические остановки. Основные
метрики: начальная успешность, исправления среди ошибочных стартов, попытки,
категории ошибок и расходы по ролям. Общий initial считается один раз.
Блоки новой серии можно анализировать совместно; предыдущие серии остаются
отдельными наблюдениями, без отбора лучших результатов. Успешные спецификации
проверяются чтением на сохранение поведения и свойств. Аудит не возвращается LLM.
Оценки описательные: восемь задач не обосновывают универсальный рейтинг методов.
