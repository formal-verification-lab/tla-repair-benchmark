# Дополнительная серия с общими правилами оформления

Эта серия выбрана после анализа базового запуска
`main-20261106T143303Z-5dc6fe`, в котором 47 из 63 ошибочных уникальных
проверок относились к заголовку MODULE. Это последующий исследовательский
эксперимент, а не заранее сформулированная независимая проверка гипотез.
Базовые данные сохраняются отдельно и не заменяются лучшими результатами.

## Что фиксируется до запуска

Конфигурация `configs/experiment-format-v2.json` сохраняет исходные модель,
версию, temperature, max_tokens, инструменты, задачи, cfg, лимит десять
попыток, правила фильтрации, выделения исходника и объяснения. Меняются:

* Начальный промпт получает общий checklist формата TLA+: разделители MODULE
  и конца файла, запятые в объявлениях, объявления и импорты операторов,
  определения имён cfg, ответ только исходным текстом.
* Выполняются три начальные генерации на задачу вместо одной: 12 исходных
  спецификаций, каждая общая для A/B/C, всего 36 ветвей.

Профиль `format-guide-v2` задан в `benchmark.runner.PROMPT_PROFILES`.
Шаблон архивируется с SHA-256, его соответствие фактически используемому
профилю проверяется до обращения к модели. Начальный checklist одинаков
во всех методах и остаётся в истории. Промпт исправления и свежий контекст
объяснителя не меняются. Прежний профиль `baseline-v1` и
`configs/experiment.json` сохранены.

В checklist нет решений конкретных задач, исправлений отдельных ошибок,
Gold или примеров из эталонов. Никакие результаты новых попыток не должны
влиять на промпт в пределах этой серии. Успех не является условием включения
прогона в анализ. Три обращения — отдельные генерации провайдера, они могут
вернуть одинаковый текст; воспроизводимый seed генерации API не заявляется.

## Запуск

После review сохранённой чистой ревизии из корня репозитория:

```sh
caffeinate -i ./scripts/run-format-v2.sh
```

Сначала скрипт выполняет пилот CigaretteSmokers с тремя начальными
генерациями, тремя методами и пределом три попытки (9 ветвей, до 27 вызовов).
При нормальном завершении автоматически начинается отдельная основная серия
в уникальном каталоге `results/main-…`: четыре задачи, три генерации,
три метода, до десяти попыток (36 ветвей, до 444 вызовов).
Неуспех модели в пилоте не блокирует серию. Техническая остановка CLI
прерывает скрипт; зарегистрированные сбои верификатора блокируют основной
запуск проверкой совместимости пилота. Старый пилот не подходит из-за
изменившегося промпта и кода.

Команда не меняет версию модели при её несовпадении с закреплённой,
не повторяет ошибки API и не покупает дополнительные пакеты. Данные пилота
и основной серии остаются раздельными. Скрипт запускает только одну серию;
последующий аудит не выполняет новых обращений автоматически.

## Заранее выбранный анализ

* Начальная успешность SANY/TLC: на 12 генерациях, отдельно от исправлений.
* Успех исправления среди неуспешных начальных генераций: парное сравнение
  A/B/C на одной исходной спецификации, с разбивкой по четырём задачам.
* Попытки до успеха и исчерпание лимита: вместе, без выдачи средних только
  по успешным ветвям за общую эффективность.
* Категории ошибок: уникальные проверки и ссылки на методы отдельно;
  технические сбои и исключения парсера сохраняются в отчёте.
* Полный вход, выход и время: общая начальная генерация отдельно,
  исправления и объяснения C раздельно. Стоимость без тарифа не выдумывается.
* Чтение всех уникальных успешных версий: не ослаблены ли свойства,
  не исчезло ли требуемое поведение, что фактически проверяет cfg.
  TLC-успех и содержательный аудит публикуются раздельно.

Сравнение с базовой серией будет описательным: начальные генерации и их
число различаются, серия выбрана после изучения базовых ошибок. Нельзя
приписать любое улучшение исключительно checklist. Основное сравнение
трёх методов проводится внутри новой серии на общих стартах. Четыре задачи
остаются четырьмя задачами, 36 ветвей не являются 36 независимыми задачами.
Если все исходники сразу проходят проверки, это результат генерации,
а не свидетельство эффективности исправлений; искусственно портить их
для получения желаемого результата не предусмотрено.
